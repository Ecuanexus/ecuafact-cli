# Ecuafact CLI

CLI de Ecuafact para emitir, seguir y descargar comprobantes electrónicos del SRI (Ecuador) desde la terminal.

```bash
npm install -g @ecuafact/cli@preview
```

También con Scoop (`scoop bucket add ecuafact https://github.com/Ecuanexus/ecuafact-scoop` y `scoop install ecuafact/ecuafact-preview`) o Homebrew (`brew install ecuanexus/ecuafact/ecuafact-preview`).

Documentación: https://docsapi.ecuafact.com/v1/guias/cli
